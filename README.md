# 班主任工作台 (Homeroom Teacher Workbench)

> 一款专为中小学班主任与任课教师设计的现代化、全功能、轻量级智慧班务协同管理平台。  
> **零外部依赖 · 纯原生标准库实现 · 支持局域网跨设备多端协同 · 数据 100% 本地安全隔离**

---

## 🌟 项目亮点

- **⚡ 零依赖极速启动**：后端基于纯 Python 3 原生标准库（`http.server`、`json`、`socket`），无需 `pip install` 任何第三方包，即开即用。
- **🌐 局域网多端协同**：办公室电脑、教室电子白板一体机、教师手机或平板均可在同一校园局域网下实时同步访问。
- **🔒 三级权限与数据隔离**：支持**超级管理员**、**班主任**、**任课教师**三级权限体系，班级间数据 100% 独立物理隔离存储。
- **📱 响应式与触控大屏模式**：完美适配 PC 桌面端、平板、手机端，内置专门针对教室希沃/鸿合触控一体机的“智慧大屏展示模式”。
- **🛡️ 纯本地化数据安全**：所有学生档案与班务数据均保存在本地 JSON 文件中，不经过任何第三方云端服务器，严格保障未成年人隐私与敏感数据合规。
- **🚀 跨平台纯 ASCII 批处理脚本**：启动脚本与防火墙配置脚本采用标准 ASCII 编码，彻底杜绝 GitHub 跨操作系统克隆及 Windows CMD 编码乱码导致的闪退问题。

## 📋 核心功能模块

平台采用左侧纵向导航栏布局，共包含 **12 大核心业务模块** + **智慧大屏** + **超级管理后台**：

| 模块序号 | 功能模块 | 核心功能简介 |
| :---: | :--- | :--- |
| **01** | **班级总览** | 工作台首页大屏，集中展示今日天气与农历、今日课表、出勤/请假即时概况、待办班务、今日值日生、今日生日提醒、学生综合表现积分与快捷操作（快速点名、记请假、发通知、留作业等）。 |
| **02** | **今日班务** | 支持学校通知、班级任务、材料收集、表格填写、费用收取、学生谈话、活动准备、安全提醒等多分类事务管理；支持优先级、截止时间、多周期重复（每日/每周/每月/自定义），未完成事项自动顺延并标红警示。 |
| **03** | **学生档案** | 全班学生一站式电子成长档案，包含基础身份、照片、健康病史与过敏源、上下学接送、家庭住址、监护人紧急联系人；支持 **Excel 批量导入/导出**、自定义标签、谈话/家访台账与成长档案打印。 |
| **04** | **考勤请假** | 支持上午/下午独立点名、一键全员出勤、快速标记迟到/病假/事假/早退；提供请假起止时间自动流转、请假材料上传留痕、月度考勤统计与异常缺勤连续预警。 |
| **05** | **课表与排班** | 一周课程表排布（带调课记录与提醒）；**可视化交互座位表**（支持鼠标拖拽调座、按身高排座、小组排座、随机换座与打印）；每日值日生分组轮换；班干部团队分工与履职考核评价。 |
| **06** | **作业管理** | 统一管理语数外等多学科作业布置、截止时间与要求；学生提交/未交/已批改/需订正/已订正状态闭环跟踪，支持一键批量登记完成、连续未交预警与优秀作业作品展示墙。 |
| **07** | **成绩与学情** | 考试成绩登记与 Excel 批量导入；班级整体分析（平均分、优秀率、及格率、各分数段分布柱状图）；学生个人历次考试雷达图与进退步轨迹；严格遵循隐私保护原则，不公开公布学生排位。 |
| **08** | **成长评价** | 涵盖课堂表现、文明礼仪、劳动卫生、团结协作等 10 大维度；支持小红花/积分徽章正向激励；记录成长事件图文故事；自动生成周表现小结、月度成长报告及期末综合素质评语初稿。 |
| **09** | **家校沟通** | 班级通知发布（支持已读/未读状态实时统计、回执确认、一键催阅）；电话、微信、面谈、家访全场景沟通纪要登记；长期未联系学生家庭智能提醒与待回访清单。 |
| **10** | **安全与健康** | 每日晨检/午检体温异常台账；学生突发安全事件应急处置记录；**1530 安全教育台账**（防溺水、交通安全、消防安全、防欺凌等），一键生成标准化迎检安全台账。 |
| **11** | **班级活动** | 主题班会、少先队活动、研学旅行、运动会、艺术节全流程管理；包含活动方案、人员分工、物资清单、安全预案、活动照片墙与图文纪要沉淀。 |
| **12** | **统计报表** | 汇总班级出勤率、作业完成率、表现积分趋势、家校沟通频次；支持导出每日班级日志、周班务总结、月度班主任工作手记、安全教育记录等标准文档。 |
| **✨** | **班级电子宠物** | 内置 15 种趣味虚拟宠物（猫咪、柴犬、熊猫、小恐龙等），学生表现良好获取积分即可为宠物升级进化，显著提升学生日常积极性与班级凝聚力。 |
| **🖥️** | **智慧大屏模式** | 专为教室前台交互一体机打造的沉浸式全屏界面，支持大屏随机抽人点名、全班积分表扬互动、光荣榜展示与课堂倒计时。 |
| **⚙️** | **超级管理后台** | 独立于前端的管理者控制台（`admin.html`），支持学校管理层创建多班级、指派班主任、审核新教师注册申请、管理任课教师科目权限。 |

## 🚀 快速上手与运行

### 方式一：一键启动完整局域网服务（推荐 · 开箱即用）

1. **环境准备**：**无需提前安装配置 Python！** 项目根目录下已内置专属便携式虚拟运行环境（`.venv`）。
2. **运行启动脚本**：
   - 直接双击项目根目录下的 **`start.bat`**。
   - 脚本将默认优先激活并运行内置的 `.venv` 虚拟环境，不管当前电脑有无安装 Python，均可开箱即用自动启动后端服务。
3. **在浏览器中访问**：
   - **本机访问**：[http://localhost:8768/index.html](http://localhost:8768/index.html)
   - **后台管理**：[http://localhost:8768/admin.html](http://localhost:8768/admin.html)

---

### 方式二：纯前端静态离线模式（无需 Python）

- 如果当前电脑未安装 Python，直接双击运行根目录下的 **`open_browser.bat`**。
- 系统将在默认浏览器直接打开 `index.html`，以浏览器本地缓存（LocalStorage）模式直接体验全部界面与排版功能。

---

### 方式三：手机 / 教室电子白板跨设备访问（局域网协同）

若要在同办公室其他电脑、手机或教室一体机上访问本平台：
1. **放行局域网端口**：
   - 鼠标右键点击 **`setup_firewall.bat`**，选择 **“以管理员身份运行”**。
   - 脚本会自动放行 Windows 防火墙 TCP `8768` 端口，并将当前网络优化为专用网络，控制台将自动打印出您的局域网 IP 地址（例如 `http://192.168.1.100:8768`）。
2. **连接同一网络**：
   - 确保手机、平板或教室一体机连接到同一个 Wi-Fi 或校园局域网。
3. **打开浏览器访问**：
   - 在手机或一体机的浏览器地址栏输入控制台打印的地址（如 `http://192.168.1.100:8768/index.html`）即可流畅使用！

## 🔒 隐私保护与数据备份建议

1. **未成年人隐私合规**：
   - 本项目在开源仓库中移除了所有真实师生隐私信息（身份证号、真实手机号、家庭住址等），预置数据均为完全脱敏的虚构示范数据。
2. **本地数据自动备份**：
   - 班主任在日常使用中录入的所有学生数据均自动保存在本地 `data/classes/` 对应班级的 `.json` 文件中。
   - 建议在学期初导入或期末总结时，在工作台底部的 **【班级设置】 -> 【数据管理】** 中点击 **“导出全量备份”**，将 JSON 备份文件妥善留存。
